ОПЛАТЫ — СТРОЙМАРКЕТ
====================

КАК ЗАПУСТИТЬ
-------------

1) Рекомендуемый вариант FOLDER (папка)
   После распаковки запускайте файл:

       Oplata\Oplata.exe

   ВАЖНО: не вытаскивайте Oplata.exe из папки Oplata отдельно.
   Рядом с ним лежат нужные программе DLL и служебные файлы.
   Если нужен быстрый доступ, создайте ярлык на Oplata\Oplata.exe
   и положите ярлык на рабочий стол.

2) Запасной вариант SINGLE-FILE (один файл)
   Запускайте Oplata.exe, который лежит рядом с этим текстом.

Установка не требуется. Данные хранятся отдельно и при обновлении
программы не стираются:

    %APPDATA%\OplataStroymarket\data.json


ВЫГРУЗКА И ЗАГРУЗКА БАЗЫ (EXCEL)
--------------------------------

Кнопки «Выгрузить базы» и «Загрузить базы» стоят в шапке программы,
справа от переключателя МИР / КОРЕЛИЧИ. Они доступны администратору.

  • Одним нажатием выгружаются ОБЕ базы сразу (МИР и КОРЕЛИЧИ) в один
    файл Excel: oplata-базы-ГГГГ-ММ-ДД.xlsx. Листы в файле называются
    «МИР. Поставщики», «КОРЕЛИЧИ. Поставщики» и так далее.
  • Файл можно открыть в Excel, проверить и поправить, затем загрузить
    обратно кнопкой «Загрузить базы».
  • Перед загрузкой программа показывает, сколько записей в каждой базе
    файла, и спрашивает подтверждение: загрузка ЗАМЕНЯЕТ данные баз.

Пользователи и пароль в файл выгрузки не попадают.


ЕСЛИ БРАУЗЕР ЗАБЛОКИРОВАЛ ЗАГРУЗКУ
----------------------------------

Так бывает с новой программой без цифровой подписи издателя: у каждого
нового EXE свой хэш, и у него ещё нет накопленной репутации. Поэтому
одна версия может скачаться спокойно, а следующая — получить
предупреждение. Полностью убрать такие предупреждения без подписи кода
нельзя, но сначала попробуйте рекомендуемый вариант FOLDER.

Разрешайте загрузку только если вы сами нажали этот файл в GitHub
Actions нашего проекта и имя артефакта начинается с:

    Oplata-windows-folder-v
или
    Oplata-windows-single-file-v

Microsoft Edge:
  1. Откройте «Загрузки» (Ctrl+J).
  2. У заблокированного файла нажмите «...».
  3. Выберите «Сохранить» / Keep.
  4. Нажмите «Показать больше» / Show more.
  5. Выберите «Сохранить в любом случае» / Keep anyway.

Google Chrome:
  1. Откройте «Загрузки» (Ctrl+J).
  2. У заблокированного файла нажмите «Ещё».
  3. Выберите «Скачать опасный файл».

Названия пунктов могут немного отличаться в зависимости от языка и
версии браузера. Не отключайте Защитник Windows или SmartScreen ради
одной загрузки. После скачивания файл можно дополнительно проверить
через контекстное меню: «Сканировать с помощью Microsoft Defender».


ЕСЛИ WINDOWS ПРЕДУПРЕДИЛА ПРИ ПЕРВОМ ЗАПУСКЕ
--------------------------------------------

Это отдельное окно SmartScreen «Windows защитила ваш компьютер».
Для файла из нашего GitHub Actions нажмите:

    Подробнее -> Выполнить в любом случае

Если кнопки «Сохранить в любом случае» или «Выполнить в любом случае»
нет, загрузку/запуск может запрещать политика организации. В таком
случае нужен администратор компьютера; окончательное решение для
будущих версий — цифровая подпись кода.
