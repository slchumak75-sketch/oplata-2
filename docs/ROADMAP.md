## Этап 1. Формулы — 🔶 начат 27.10.2026 (v0.3.0, только «Поставщики»)

Пользователь дал правила поставки/долга (SPEC п. 2/6, ADR-007) — они
реализованы в `calc.py`. Остальные формулы по-прежнему не выдумывать.

Сделано:
- [x] Срок оплаты: дата + отсрочка; предоплата/реализация — без отсрочки;
      перенос с выходного на следующий рабочий день по календарю «Данные»
- [x] «Долг» на срок, «за неделю», «на сегодня»; «Долг» — архивный (v0.3.1):
      оплата его пока НЕ уменьшает, правила оплат — отдельным этапом

Осталось спросить пользователя:
1. Как оплата влияет на долг/просрочку и распределяется между поставками?
   (Пользователь отложил до «этапа оплат»; входящий остаток — туда же.)
2. ✅ «Долг» показывает исходную сумму срока и остаётся для архива (v0.3.1)
3. «На сегодня» — от реальной даты или от показанной недели? (SPEC Q9)
4. Отсрочка 0 («срок вручную») — где вводится ручная дата срока?
5. Формулы «Сводки»: всего/просрочено/сегодня/7 дней/приход и оплачено за месяц, ближайший срок.
6. Кнопка «Очистить суммы» — что именно очищает?
7. Для покупателей окно «Реализация» сделано (v0.8.0), срока у реализации
   нет. Остаётся спросить формулы долга/просрочки покупателей.
